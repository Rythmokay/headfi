### Post #3 by **Member** ()

Since dx340 can be enabled with Desktop mode!  It essentially has the amplifier to run off from stock DAP standard voltage of +/-8V.  The Desktop mode will allow running +/-12V and the improved performances can be observed.

The stock 12V adapter is provided with the player and in the box.  It is not a charger by any means.  You can only charge with USB C.

The socket for the plug sizes is 3.5mm x 1.35mm DC barrel plug.  The inner polarity is Positive and outside is negative

Linear Power Supply is recommended, and as far as with different builts, slight differences in audio performances will be observable.  Whatever yoy are using, just make sure that Voltage is 12V within 10% variations.  The minimum Amperage is 1.5A.  There is no need to worry about over Amperage, because the player can only and will only draw as much current as needed.  For example, using a 100W LPSU with 12V output is fine

The one I personally recommend if sky is the limit, would be customized Sigma 11 with all the audiophile grades components as possible!

The cheapest is Fiio 12V LPSU

Then there are oceans of other units on the market

LHY 12VDC is the best fit right now for my use cases.  There are others but I have not gone through and testing them.
