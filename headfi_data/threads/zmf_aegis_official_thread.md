This is a thread to discuss the collaboration between ZMF and 
@L0rdGwyn
 on a commercial version of the wonderful Aegis amp that he designed and released to the world.

Here are some preliminary pics of the production version of the amplifier:

You can read about the origins of the amp in L0rdGwyn's thread here:  
https://www.head-fi.org/threads/aegis-diy-tube-headphone-amplifier.965530/

The production version adds a few features, including 3 different headphone outputs (1/4, XLR and 4.4mm).  The 4.4mm is attenuated for use with sensitive IEMs.

The production version power supply can handle 3A current draw, so it can handle 5U4G tubes, which the DIY version cannot.

The amp will come stock with 6SL7 input tubes, EL34 power tubes and a 5AR4/GZ34 rectifier tube.

### Post #3 by **Member** ()

Very excited for this release!  In this post, want to include some useful information for new or potential buyers:

Dimensions: 11.25" L x 14.25" W x 8"H (with stock tubes, may be taller using adapters)

Weight: 46lbs

Input impedance: 20kOhms.

Output impedances:

1/4" Low: 5ohms

1/4" Med: 11ohms

1/4" High: 31ohms

XLR Low: 11ohms

XLR Med: 28ohms

XLR High: 85ohms

For the 4.4 Pentaconn connection, there is a resistor voltage divider for use with high sensitivity IEMs.  Meant to be used on "Low" setting.  Output impedance: 2ohms

Frequency response: -3dB from 11Hz - 33kHz

THD+N at 1mW: < 0.05%

Power output: 1 - 2.5W depending on load and impedance setting.

Tube compatibility spreadsheet: 
https://docs.google.com/spreadsheets/d/1eICoQGaoQ1eOI4JK045xLZDdUs3u9UPJVXXje0g_S3w/edit?usp=sharing

I'll update the spreadsheet as we go and tubes are confirmed or denied compatibility.
